# Instalação — TAJO TAP V4.4

1. Não rode novamente as migrations 001–006 apenas para corrigir a ativação.
2. Substitua o código do repositório pela V4.4.
3. Confirme que `/api` contém somente `index.js`.
4. Commit/push para `main`.
5. Aguarde o deploy Vercel ficar `Ready`.
6. Abra `/api/health` e confirme `ok: true`.
7. Reabra a mesma plaquinha em `/atv/TT-XXXXXX` e conclua a ativação.
8. Depois teste `/q/TT-XXXXXX`.

O motor V4.4 usa a Data API diretamente no backend e não depende das RPCs de ativação que estavam gerando `PGRST202`.
