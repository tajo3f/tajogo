# Instalação — TAJO TAP V4.2

## 1. Supabase
Execute somente:

`supabase/migrations/005_admin_pin_and_bulk_management.sql`

Não execute novamente 001, 002, 003 ou 004 se já foram aplicadas.

A migration adiciona `admin_pin` em `tap_plate_activation_codes`. PINs antigos não podem ser recuperados a partir do hash; para uma unidade antiga ainda não ativada, abra a plaquinha no painel e use **Gerar PIN visível**.

## 2. GitHub / Vercel
Substitua os arquivos do projeto pela V4.2 e faça commit com exclusões incluídas:

```bash
git add -A
git commit -m "TAJO TAP V4.2 - PIN administrativo e exclusão em massa"
git push origin main
```

A estrutura continua usando apenas `/api/index.js` como Serverless Function na Vercel.

## 3. Testes recomendados
1. Criar uma nova plaquinha e confirmar que o PIN aparece na lista e nos detalhes.
2. Recarregar o painel e confirmar que o mesmo PIN continua visível ao Super Admin.
3. Em uma plaquinha legada pendente, usar **Gerar PIN visível** e testar `/atv/TT-XXXXXX`.
4. Selecionar 2–3 plaquinhas de teste e usar **Excluir selecionadas**.
5. Criar um lote pequeno, fechar o modal, voltar em Produção e baixar novamente o mapa interno CSV.
