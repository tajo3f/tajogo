# TAJO TAP BUSINESS V8.1 — Publicação

## O que esta versão corrige
- Aplica a nova logomarca oficial TAJO TAP BUSINESS.
- Corrige o problema crítico da ativação em celular no qual os dados digitados podiam ficar invisíveis.
- Corrige autofill do Safari/Chrome Mobile em campos escuros.
- Mantém os dados digitados ao alternar entre criação de conta e conta existente.
- Preserva todos os recursos e migrations da V8.0.

## Banco de dados
**Não existe migration nova na V8.1.**

Se o projeto já está na V8.0 e a migration `011_v8_business_operator.sql` já foi aplicada, não rode nenhuma migration adicional.

Se estiver vindo de uma versão anterior à V8.0, siga primeiro `V8-INSTALACAO.md` e aplique a migration 011 conforme as instruções daquele arquivo.

## Publicação
1. Faça backup do projeto atual e do Supabase.
2. Substitua os arquivos da aplicação pela V8.1.
3. Preserve as variáveis de ambiente do projeto publicado.
4. Faça o deploy normalmente.
5. Em celular, feche abas antigas do sistema e reabra o endereço para evitar CSS antigo em cache.
6. Teste uma plaquinha ainda não ativada em um aparelho Android e, se disponível, em um iPhone.

## Teste obrigatório da ativação
No fluxo público de ativação, confira:
- Nome digitado aparece imediatamente.
- Estabelecimento digitado aparece imediatamente.
- E-mail digitado aparece imediatamente.
- WhatsApp digitado aparece imediatamente.
- Senha aparece mascarada normalmente.
- Alternar “Criar minha conta” / “Já tenho uma conta” não apaga nome, empresa, e-mail ou telefone.
- Continuar para a próxima etapa mantém os dados.
- A ativação conclui e o cliente consegue entrar no painel.
