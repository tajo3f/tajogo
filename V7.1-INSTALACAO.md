# TAJO TAP V7.1 — Instalação

Esta versão corrige a troca repetida de destinos. **Não há migration nova de banco para a V7.1.**

## Se você já está na V7.0
1. Não execute novamente as migrations do Supabase.
2. Substitua os arquivos do projeto pelos da V7.1.
3. Confirme que `/api` contém apenas `index.js`.
4. Faça commit e push para a branch conectada à Vercel.
5. Aguarde o deployment ficar `Ready`.
6. Faça login e teste a mesma plaquinha:
   - Smart Page → Instagram;
   - Instagram → WhatsApp;
   - WhatsApp → Localização;
   - Localização → Smart Page.

O QR físico deve permanecer o mesmo durante todo o teste.

## Supabase
A pasta `supabase/migrations/` continua contendo todas as migrations acumuladas até a V7. O banco existente não precisa de alteração para esta correção.
