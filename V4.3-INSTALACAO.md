# Instalação da V4.3 em um ambiente V4.2 existente

1. No Supabase SQL Editor, execute **somente** `supabase/migrations/006_activation_v4_3_hotfix.sql`.
2. Confirme que o SELECT final mostra `tap_validate_activation_pin_v4(...)` e `tap_activate_plate_v4(...)`, sem `NULL`.
3. Atualize o mesmo repositório GitHub com a V4.3 (`git add -A`, commit e push).
4. Aguarde o deployment ficar `Ready` na Vercel.
5. Teste novamente a mesma plaquinha; não é necessário recriá-la.
6. Depois teste o QR permanente `/q/TT-XXXXXX` para confirmar o redirecionamento.

Não execute novamente 001–005 apenas por causa deste hotfix.
