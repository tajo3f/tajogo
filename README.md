# TAJO TAP V4.4

Versão de estabilização do fluxo de ativação. Mantém módulos de vendedores, chat da equipe, produção em lote, PIN administrativo e exclusão em massa, e substitui o fluxo público de ativação por um motor server-side baseado na Data API, sem dependência de RPCs PostgREST para ativar plaquinhas.

Consulte `V4.4-INSTALACAO.md` e `CHANGELOG-V4.4.md`.
